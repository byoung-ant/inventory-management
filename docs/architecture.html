Key Patterns & Conventions

Data Loading in Views

Each view uses a consistent async pattern: loading, error, and data refs. Data is fetched on onMounted and re-fetched whenever the filter state changes via a deep watch.

Reactivity: Refs + Computed

Raw API data lives in ref([]) (e.g., allOrders, inventoryItems). Derived/transformed data lives in computed(). Client-side search filtering is always a computed property over the raw ref.

v-for Keys

Always use unique domain keys (e.g., item.sku, order.id, month.month) in v-for loops — never array index — to avoid Vue reconciliation bugs.

Date Validation

Always validate dates before calling .getMonth() or similar methods. The data uses ISO 8601 format (YYYY-MM-DDTHH:MM:SS). Backend filters parse date strings safely and handle null/missing dates gracefully.

Backend Filter Safety

Filters never mutate the original in-memory arrays. All filtering operates on copies. A filter value of 'all' is treated as "no filter applied" — the backend skips that dimension entirely.

No External Chart Library

All charts are rendered with custom SVG and CSS Grid layouts. No Chart.js, D3, or similar dependencies. Design follows the slate/gray palette: #0f172a, #64748b, #e2e8f0.

Known Limitations

⚠ Tasks API not implemented — The frontend calls /api/tasks (GET/POST/DELETE/PATCH) but the backend has no such endpoints. TasksModal will receive 404 errors.
⚠ Purchase Orders unimplemented — purchase_orders.json is empty. POST /api/purchase-orders has no backend handler. The backlog detail modal cannot create purchase orders.
⚠ Backlog.vue has no route — The component exists at client/src/views/Backlog.vue but is not registered in the Vue Router config in main.js, making it unreachable from the UI.
⚠ No data persistence — All data is loaded from JSON files into memory at server startup. Any in-flight state (if it were writable) would be lost on restart.
⚠ Mock authentication only — useAuth.js contains a hardcoded user (John Doe). There is no real login flow, session management, or authorization.
